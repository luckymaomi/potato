# Media Archive

## 完成标准

- 供应商成功不是媒体完成。媒体必须下载、校验签名、原子写入项目目录并持久化 generation 后，才能返回本地 URL。
- 每次生成创建独立历史记录；切换当前版本只改指针，不覆盖旧记录或旧文件。
- 供应商失败、本地下载失败、归档失败和合成失败保留各自阶段，不互相冒充。

## 参考图与交付包

- 参考图数组属于单个节点；创建、恢复、复制和更新都复制数组，异步上传不得写入后来选中的节点。
- 本地参考图仅在 Provider 调用边界转换为带 MIME 的 Data URL，不把 localhost 路径交给供应商。
- 成片下载只允许当前选用、已完成且本地存在的合成视频；禁止使用供应商 URL 或任意静态 URL 冒充本地成片。
- 镜头包按分镜顺序流式写出当前镜头视频、分镜图、绑定资产标准图与文本 meta；ZIP 只是传输容器，不得恢复项目状态或写入 generation 历史、输入参考图。
- 按整集或选中镜头导出时都要防路径穿越、校验本地文件存在性，并在成功或失败后清理传输临时文件。

## 验证

- 使用真实文件签名和磁盘存在性测试归档；用多节点测试参考图隔离；用含历史媒体的交付测试确认仅输出当前媒体与绑定标准图。
