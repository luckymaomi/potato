# Media Archive

## 完成标准

- 供应商返回图片地址后，generation 可先进入 `remote`：业务指针与界面主图指向远程 URL（远程就是远程，无魔法）。
- 后台有界重试本地归档（下载超时、次数上限）；成功后 status=`completed`，指针切到 `/static/...`。`available` 仅表示本地文件真实存在。
- 本地上传仍直接归档为 `completed`，不走远程预览。
- 每次生成创建独立历史记录；切换当前版本只改指针，不覆盖旧记录或旧文件。
- 供应商失败、本地下载失败、归档失败和合成失败保留各自阶段，不互相冒充；归档失败不应抹掉已可见的远程预览。
- 服务重启只失败 `async_tasks` 不够：必须同步回收仍停在 `pending/processing` 的 `image_generations`，否则业务侧会误报「已有进行中任务」且前端无停止入口时会死锁。`remote` 记录由归档重试循环继续处理，不因重启标失败。

## 参考图与交付包

- 参考图数组属于单个节点；创建、恢复、复制和更新都复制数组，异步上传不得写入后来选中的节点。
- 本地参考图仅在 Provider 调用边界转换为带 MIME 的 Data URL，不把 localhost 路径交给供应商。
- 成片下载只允许当前选用、已完成且本地存在的合成视频；禁止使用供应商 URL 或任意静态 URL 冒充本地成片。
- 镜头包按分镜顺序流式写出当前镜头视频、分镜图、绑定资产标准图与文本 meta；ZIP 只是传输容器，不得恢复项目状态或写入 generation 历史、输入参考图。
- 按整集或选中镜头导出时都要防路径穿越、校验本地文件存在性，并在成功或失败后清理传输临时文件。

## 验证

- 使用真实文件签名和磁盘存在性测试归档；用下载失败用例证明 remote 预览保留与重试后切本地；用多节点测试参考图隔离；用含历史媒体的交付测试确认仅输出当前媒体与绑定标准图。
