# Media Archive

## 完成标准

- 供应商成功不是媒体完成。媒体必须下载、校验签名、原子写入项目目录并持久化 generation 后，才能返回本地 URL。
- 每次生成创建独立历史记录；切换当前版本只改指针，不覆盖旧记录或旧文件。
- 供应商失败、本地下载失败、归档失败和合成失败保留各自阶段，不互相冒充。

## 参考图与项目归档

- 参考图数组属于单个节点；创建、恢复、复制和更新都复制数组，异步上传不得写入后来选中的节点。
- 本地参考图仅在 Provider 调用边界转换为带 MIME 的 Data URL，不把 localhost 路径交给供应商。
- ZIP 上传流写临时磁盘并逐条目校验、解压；导出流式写媒体。禁止重新引入整包内存读取或人为大小上限。
- 导入防路径穿越，重建 ID、generation 指针和画布引用；成功或失败都清理传输临时文件。

## 验证

- 使用真实文件签名和磁盘存在性测试归档；用多节点测试参考图隔离；用含历史媒体的往返测试项目归档。
