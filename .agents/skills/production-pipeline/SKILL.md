# Production Pipeline

## 核心合同

- `frontend/src/features/production/catalog.ts` 是节点角色、参数、方法和命令构造的唯一 owner。
- 节点面板参数构成完整本地输入；直接入边只追加已经完成的上游结果，不读取隐式父节点、祖先或资产仓库。
- 单节点只运行自己；下游、全部和未完成范围共用 `runWorkflow`，仅由范围筛选和 DAG 拓扑决定差异。

## 修改路径

1. 先画清插件输入、命令、后端生产入口、结果和持久化消费者。
2. 改节点合同时同步目录、上下文解析、执行器、工作区定义和结构测试，不建立第二套角色判断。
3. 保持循环明确拒绝；整图按拓扑运行，下游只消费运行到该点时可用的直接上游结果。
4. Demo 初始化只写预设数据和画布，不能刷新模型目录或提交真实生成。

## 验证

- 保护节点自治、显式入边、拓扑顺序、循环拒绝、三种运行范围和十路视频汇聚。
- 随机模型内容只验证非空结果与真实媒体落盘，不写字面量或精确内容断言。
