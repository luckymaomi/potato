# Provider Integration

## 分层

- 通用合同、注册中心、HTTP 传输、轮询运行时和供应商适配器分别维护；业务服务不得按供应商名称分支。
- 模型、模式、参考图上限和画幅来自实时目录或已核验协议，不在前端猜测。
- Agnes 与 PearAPI 凭据、路径和请求体严格隔离，不做跨供应商回退。

## 运行约束

- 文本、图片和视频生成请求不设置本地等待上限，Undici 响应头和响应体超时也必须显式关闭；目录等非生成查询可保留短超时。取得供应商任务 ID 后不设本地累计失败截止线，持续轮询到供应商终态或用户停止。
- 429 和明确暂时性错误采用可取消的有界退避；耗尽后保留供应商错误，不改写成功。
- 只有供应商明确返回百分比时才写进度；未知时只写阶段。轮询次数和经过时间不得伪造百分比。
- 日志记录阶段、供应商、模型、任务标识和结构化失败，但必须脱敏凭据、查询串和媒体正文。

## 验证边界

- 确定性测试覆盖映射、能力拒绝、超时、重试和取消。
- 真实外部验收必须有 owner 授权和凭据证据；Mock、HTTP 200 或任务已提交不能证明媒体生成成功。
