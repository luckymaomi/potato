# 番茄短剧

本地 AI 短剧制作工作台。当前主链：

`人工剧本 → 项目资产卡与标准资产图 → 分镜台 → 分镜图 → 镜头视频 → 整集合成`

项目之间完全隔离。一个项目的角色卡、场景卡和道具卡可由该项目下各集按 ID 复用。

## 制作区

- **总览与剧本**：人工编辑项目故事总览和当前剧集剧本。
- **项目资产库**：建立角色卡、场景卡和道具卡；填写结构化文本、上传生成输入参考图，并生成或上传标准资产图。
- **分镜台**：人工填写镜头规格、选择本项目资产卡和本镜额外参考图；后端一次编译图片配方与视频配方。分镜图在此生成或上传。
- **生产**：以当前分镜图为首帧，消费分镜台的视频配方生成单镜视频；全部镜头完成后合成本集成片。

文本和图片是两条独立通道：资产卡结构化文本进入提示词，资产标准图与本镜额外参考图进入 reference 数组。前端只提交规格和模型参数，不组装最终提示词。

故事、剧本、资产卡和分镜清单均由用户人工编辑；产品不提供 AI 写剧本、提取资产或拆分分镜入口。

## 运行

需要 Node.js 20.9 或更高版本。

后端：

```powershell
cd backend
npm.cmd install
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd run dev
```

另开终端启动前端：

```powershell
cd frontend
npm.cmd install
npm.cmd test
npm.cmd run lint
npm.cmd run dev
```

默认地址：前端 `http://localhost:3012`，后端 `http://localhost:5679`。前端通过 `/api` 和 `/static` 代理到后端。

## AI 配置

供应商凭据只读取仓库根目录私有 `config.yaml`。模型选择顺序为：本次请求显式模型、AI 配置页默认预设、实时目录自动选择。

图片画幅、视频画幅、视频时长和参考图数量均按实时模型目录声明校验。生成任务返回本地任务 ID 并持续轮询；成功媒体归档到本地后才更新资产、分镜或剧集的当前版本指针。

## Demo

在空数据库中运行：

```powershell
python init_demo.py
```

Demo 写入《红女王》的故事、人工剧本、9 张项目资产卡和 5 条分镜规格，不调用真实供应商。实际生成媒体前需要在 AI 配置页设置可用模型。

清理仓库内本地数据库和归档媒体：

```powershell
python clear_database.py
```

## 项目归档

项目导出 ZIP 保存项目文本、项目资产卡、分镜、generation 历史、本地媒体和本地参考图。当前 ZIP 格式为 `format: 4`；导入重建 ID 与本地媒体路径，不依赖供应商原始媒体链接，也不兼容旧格式。

详细当前事实与验收合同见 [spec.md](./spec.md)。
