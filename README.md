# 番茄短剧

本地 AI 短剧制作工作台。项目按短剧制作的顺序组织：

`剧本 → 资产图 → 分镜台 → 生产`

打开项目后默认进入剧本。每个项目壳包含四个制作区：总览与剧本、资产图、分镜台、生产。首页按项目分组，分组内可折叠查看各集。

## 制作区

- **总览与剧本**：人工保存故事总览和本集剧本；文本创作不调用 AI。
- **资产图**：在同一画廊管理人物、场景和道具，可按类型和自定义标签筛选。可上传参考图、文生图或图生图，并在历史中「选用这张」。全局资产库位于资产图工作台内；「生成未完成资产图」会按顺序逐项处理并可停止。
- **分镜台**：按镜头顺序排布并通过缩略图直接选择本镜人物、场景和道具。每镜可编辑剧情、景别、机位、运镜、构图、动作、对白、光线、氛围、声音和提示词。后端统一组装资产文本、资产图与镜头字段生成分镜图；图片 prompt 可写九宫格，视频 prompt 强制表达单一连续画面。单画面画幅跟随当前图片模型能力；「生成未完成分镜图」按镜头顺序逐项处理并可停止。
- **生产**：按镜头查看分镜图和镜头视频，支持单镜视频与整集合成；展示图片/视频模型及其目录画幅能力；每个镜头单独选择视频时长与视频画幅。生产页的「生成未完成视频」只处理已有分镜图的镜头，按顺序逐项运行并可停止。分镜图请在分镜台生成。

生成任务会显示真实经过秒数；刷新页面后，进行中的任务仍会恢复计时并继续轮询，直到完成、失败或取消。任务完成、失败和停止由统一的友好反馈投影展示，工作区只负责显示当前进行中的项目和队列进度。

## 运行

需要 Node.js 20.9 或更高版本。

```powershell
cd backend
npm.cmd install
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd run dev
```

另开终端启动前端：

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

默认地址：前端 `http://localhost:3012`，后端 `http://localhost:5679`。前端通过 `/api` 和 `/static` 代理到后端。

## AI 配置与任务

供应商凭据只读取仓库根目录私有 `config.yaml`。模型选择顺序为：本次请求显式模型、AI 配置页全局预设、实时目录自动选择。默认模型预设在选择后自动保存。

图片和视频由供应商异步提交并轮询到明确结果；本地接口先返回任务 ID，前端轮询本地任务。视频最多同时处理一项。图片完成不会自动提交视频，视频需要用户明确点击，整集合成要求每个镜头都有视频。图片画幅与视频画幅分别读取对应模型目录能力，不使用通用写死比例表；视频时长只接受当前视频模型声明的档位，且每个镜头可单独选择。

## Demo

在空数据库中运行（推荐根目录便捷脚本）：

```powershell
python init_demo.py
```

Demo 写入成人向宫廷复仇悬疑短剧《红女王》的故事、剧本、9 项项目资产和 5 条分镜规格，不调用真实供应商。生成资产图、分镜图和视频前，请在 AI 配置页设置可用模型。

直接删除仓库内 `backend/data` 本地数据目录（包含数据库、WAL/SHM 和归档媒体）：

```powershell
python clear_database.py
```

## 归档

项目导出为 ZIP，包含项目文本、全局资产快照、项目资产、分镜、generation 历史和本地媒体。导入会重建 ID 和本地媒体路径，不依赖供应商原始链接。
