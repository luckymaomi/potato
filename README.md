# 番茄短剧

本地 AI 短剧制作工作台。当前主链：

`人工剧本 → 项目资产卡与标准资产图 → 分镜台 → 分镜图 → 镜头视频 → 整集合成`

项目之间完全隔离。一个项目的角色卡、场景卡和道具卡可由该项目下各集按 ID 复用。

## 制作区

- **总览与剧本**：人工编辑项目的核心钩子、世界观、主线、基调、参考设定，以及当前集的目标、冲突、转折、结尾钩子、场次节拍和剧本文本。
- **项目资产库**：建立角色卡、场景卡和道具卡；填写普通文本资料，选择产出预设并点击“组装提示词”，在独立区域查看、修改或重写完整提示词，逐张生成或上传标准资产图。
- **分镜台**：人工填写镜头规格、选择本项目资产卡和本镜额外参考图；点击“组装两份配方”后，由后端一次编译图片配方与视频配方，用户可见、可编辑并保存。上游资产、镜头规格或首帧变化会标记图片、视频待复核或配方待重装，用户可按镜确认或重跑。左侧媒体区生成或上传分镜图，右侧媒体区以当前分镜图为首帧消费视频配方生成单镜视频；待复核视频不能参与整集合成。

文本和图片是两条独立通道：分镜组装使用资产卡结构化文本、标准图与本镜额外参考图；资产图生成使用用户保存的完整产出提示词及生成输入参考图。选择预设、修改字段或打开页面都不会自动组装；生成只消费已保存的最终文本和引用快照。前端不复制后端配方拼接规则。

每个造型、场景光影设定和道具状态都是独立资产卡与独立 ID。角色布局 A-D、场景产出类型和道具产出类型只是组装预设；修改资产资料和刷新状态不会覆盖最终文本。资产图与分镜图按单张生成；资产缩略图显示排队、生成、归档、完成或失败状态。

故事、剧本、资产卡和分镜清单均由用户人工编辑；产品不提供 AI 写剧本、提取资产或拆分分镜入口。

进入项目后默认打开“总览与剧本”。项目壳以当前项目和当前剧集为上下文，左侧阶段导航切换到资产图或分镜台。

## 运行

需要 Node.js 20.9 或更高版本。

后端：

```powershell
cd backend
npm.cmd install
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd run dev
```

另开终端启动前端：

```powershell
cd frontend
npm.cmd install
npm.cmd test
npm.cmd run lint
npm.cmd run dev
```

默认地址：前端 `http://localhost:3012`，后端 `http://localhost:5679`。前端通过 `/api` 和 `/static` 代理到后端。

## AI 配置

供应商凭据只读取仓库根目录私有 `config.yaml`。AI 配置页只展示图片与视频模型；生成必须手选：AI 配置页保存图片/视频默认预设，制作页再显式选择图片画幅、视频画幅和（目录声明档位时的）视频时长。缺少任一必选手选值时，资产页与分镜台禁用生成并显示原因，后端同样拒绝静默兜底。刷新模型目录的成功提示按「图片 X / 视频 Y」分项计数，不与当前 Tab 过滤列表混报。

图片画幅、视频画幅、视频时长和参考图数量均按实时模型目录声明校验。资产页会把选择的图片画幅传给后端；未知能力不注入通用比例或参考图上限。后端在分镜图生成前检查已保存且未过期的配方、出场资产和角色/场景标准图；视频生成拒绝九宫格、分屏、多宫格等污染首帧的配方。生成任务返回本地任务 ID 并持续轮询；成功媒体归档到本地后才更新资产、分镜或剧集当前使用的 generation 指针。

前端样式唯一入口为 `frontend/src/theme/app.css`（含日夜间 Token）；工作区滚动由各页子滚动 owner 承担，不恢复已删除的 `index.css`。

## Demo

在空数据库中运行：

```powershell
python init_demo.py
```

Demo 写入《红女王》的故事、人工剧本、9 张项目资产卡和 5 条分镜规格，不调用真实供应商。实际生成媒体前需要在 AI 配置页设置可用模型。

清理仓库内本地数据库和归档媒体：

```powershell
python clear_database.py
```

## 项目归档

项目导出 ZIP 保存项目文本、项目资产卡产出提示词、分镜规格、图片/视频最终配方与引用快照、复核状态、generation 历史、本地媒体和本地参考图。当前 ZIP 格式为 `format: 8`；导入重建 ID 与本地媒体路径，不依赖供应商原始媒体链接，也不兼容旧格式。

详细当前事实与验收合同见 [spec.md](./spec.md)。
