# tomato-ai-drama

本地 AI 短剧制作工作台。项目按短剧制作的顺序组织：

`剧本 → 资产图 → 分镜台 → 生产`

打开项目后默认进入剧本。每个项目壳包含四个制作区：总览与剧本、资产图、分镜台、生产。

## 制作区

- **总览与剧本**：保存故事总览和本集剧本，可调用文本模型生成或改写剧本。
- **资产图**：在同一画廊管理人物、场景和道具，可按类型和自定义标签筛选。资产的核心是名称、当前选定图片、图片描述和标签；可以上传参考图，使用文生图或图生图，并在历史中选用图片。全局资产库位于资产图工作台内。
- **分镜台**：按镜头顺序排布并通过缩略图直接选择本镜人物、场景和道具。每镜可编辑剧情、景别、机位、运镜、构图、动作、对白、光线、氛围、声音、时长和提示词，所有字段都可以留空。单张分镜图的单画面、六宫格、九宫格、十六宫格和自定义网格只作为提示词参数，不会拆成多个镜头。
- **生产**：按镜头查看分镜图和镜头视频，支持单镜和批量操作。图片任务可以并发；视频最多同时处理一项。图片完成不会自动提交视频，视频需要用户明确点击，整集合成要求每个镜头都有视频。

全局资产库可以把图片加入多个项目；项目资产保存当前选用的图片和描述，历史图片仍可单独选用。

## 运行

需要 Node.js 20.9 或更高版本。

```powershell
cd backend
npm.cmd install
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd run dev
```

另开终端启动前端：

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

默认地址：前端 `http://localhost:3012`，后端 `http://localhost:5679`。前端通过 `/api` 和 `/static` 代理到后端。

## AI 配置与任务

供应商凭据只读取仓库根目录私有 `config.yaml`。模型选择顺序为：本次请求显式模型、AI 配置页全局预设、实时目录自动选择。

图片和视频由供应商异步提交并轮询到明确结果；本地接口先返回任务 ID，前端轮询本地任务。批量图片先完成本镜引用的资产图，再并发生成分镜图；视频统一串行。429 和暂时性错误只在当前项目内退避重试，首次提交不会盲目重发。视频时长由所选模型能力决定，页面不接受任意秒数。

## Demo

在空数据库中运行：

```powershell
cd backend
npm.cmd run init:rainy-night-demo
```

Demo 只写入故事、剧本、项目资产和十条分镜规格，不调用真实供应商。生成图片和视频前，请在 AI 配置页设置可用模型。

## 归档

项目导出为 ZIP，包含项目文本、全局资产快照、项目资产、分镜、generation 历史和本地媒体。导入会重建 ID 和本地媒体路径，不依赖供应商原始链接。
