# tomato-ai-drama

本地 AI 短剧生成工作台：在一个 React Flow 画布里完成“故事 → 剧本 → 角色/场景/道具资产 → 资产图 → 分镜清单 → 分镜图 → 镜头视频 → 整集”。

运行环境要求 Node.js 20.9 或更高版本。

## 当前能力

- React 18 + TypeScript + Vite 前端
- 项目列表：新建、打开、流式导入 ZIP、流式导出 ZIP；归档携带本地图片、视频和全部生成历史
- AI 配置：从根配置读取 Agnes/PearAPI，页面查看状态、同步实时模型目录，并可分别预设可留空的文本/图片/视频默认模型
- 插件化节点目录统一声明角色、输入输出、参数、默认提示词、生成方式和执行命令；画布核心不维护第二套节点规则
- 节点拖动、缩放、平移、框选、多选和自由连线
- 节点自治：右侧面板是本节点的完整输入；单节点运行只运行自己，连线只追加已完成直接上游的数据，删除连线后仍可独立运行
- 运行反馈：顶部显示当前运行范围的真实完成数和当前阶段，节点、检查器与顶部按秒显示本次真实耗时；只有供应商明确返回百分比时才显示百分比，不按耗时或轮询次数伪造进度
- 点击单个节点会以完整轮廓高亮它的直接邻居并加粗对应连线；高亮不改变多选、运行范围或持久化快照
- 可靠自动保存：业务快照防抖合并、串行写入、保存状态可见、失败重试和 revision 冲突保护
- 文生图、图生图、文字 + 多参考图共同生成、文生视频、图生视频
- 图片与视频画幅比例跟随实时模型能力：节点只显示当前模型支持的比例，后端在创建任务前再次校验
- 参考图支持 URL 与本地多图上传，下方直接显示可预览、可删除的缩略图；每个节点独立持有自己的参考图列表，本地图片仅在调用时转换为 Base64
- 图片生成结果在右侧检查器直接显示缩略图，并保留大图预览和新窗口打开；视频结果提供内嵌播放预览
- 角色/场景/道具资产图生成；资产图是跨镜头复用的标准图，分镜图是单个镜头画面
- 图片和视频只有下载并校验到项目本地后才算完成；供应商 URL 只作来源记录，供应商失败与本地保存失败分开显示
- 每次媒体生成和整集合成都保留历史，可在当前节点直接回看并切换已落盘旧版本
- 模型下拉只显示模型标识，生成能力单独换行展示；历史版本使用时间、短编号和缩略内容，检查器不会被长能力文本横向撑开
- 文本节点可纯手动，也可选配文本 API；六类默认系统提示词在检查器中完整可见、可编辑、可恢复默认
- 手动剧本运行后会写入关联剧集，后续提取和分镜也可直接消费连线传来的文本
- “运行整个画布”按完整显式 DAG 拓扑排序并执行全部节点；“运行未完成”只执行缺失或失效节点；单节点只执行自己。节点可在检查器中“标记为已完成”，所有运行范围都会跳过它，关闭开关后恢复执行；标记不会伪造输出，下游仍只消费真实完成结果
- 画布内提交整集合成
- Everything 持久日志：默认写入 `backend/logs/everything.log`，覆盖 HTTP、CRUD、画布、生产命令、任务、供应商、本地归档、合成和验收脚本，并自动脱敏凭据与二进制内容
- 《雨夜外卖》预写 Demo v19：36 个节点、56 条显式数据边和 1 个工作流组；分镜图初始化为 `1:1` 九宫格故事板，资产图和镜头视频保持 `9:16`，每个镜头视频默认 15 秒；所有 AI 节点默认自动选择模型，镜头描述直接属于分镜图/视频节点

后端 `backend` 是本项目的独立服务端目录，接口前缀为 `/api/v1`；前端和后端均以 `tomato-ai-drama` 为项目名。

## 快速开始

先启动后端：

```powershell
cd backend
npm.cmd install
npm.cmd run dev
```

另开终端启动前端：

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

后端也可以先构建再运行 `npm.cmd run build`、`npm.cmd run start:dist`。供应商采用统一核心合同 + 独立适配器设计，当前只注册 Agnes 与 PearAPI，两者都按实时目录声明文本、图片和视频能力；新增供应商时增加独立适配器并注册，不修改文本、图片或视频业务服务。没有真实凭据时不会把请求桩或模板占位内容当成生成成功。

文本、图片和视频生成请求不设置本地超时；取得异步任务 ID 后也不设置累计等待上限，只等待供应商明确成功、明确失败或用户主动停止。模型目录等非生成查询仍使用短超时。

首次运行先复制根配置并填写所需供应商凭据：

```powershell
Copy-Item config.example.yaml config.yaml
```

模型来自供应商实时目录。刷新目录后，可在 AI 配置页分别选择文本、图片和视频的全局默认模型，三项都允许留空；节点自己选定的供应商或模型始终优先，未设置全局预设时按实时目录中的实际能力自动选择。`config.yaml` 只保存供应商连接所需的 Key、Base URL 和启用开关，不保存模型选择。模型目录同时声明文生/图生模式、参考图上限和画幅比例；比例能力未知的媒体模型不会被静默当作可用。`config.yaml` 已被 Git 忽略，不要提交或分享。

PearAPI 图片与视频统一使用官方 `/v1` 协议：图片 `/v1/images/generations`、视频 `/v1/video/generations`，统一通过 `Authorization: Bearer <sk-...>` 鉴权。异步任务分别轮询 `/v1/images/tasks/{id}` 和 `/v1/video/generations/{task_id}`。Grok Imagine Video 1.5 按专栏合同提交 `mode`、`seconds`、`aspect_ratio` 与 `images`，不再发送旧兼容字段。

PearAPI 图片固定使用异步任务协议：提交成功取得任务 ID 后持续轮询供应商终态。轮询查询遇到暂时性网络错误会继续等待并写入 Everything 日志；初次生成提交不会因网络异常盲目重发，避免同一请求重复扣费。已有可用结果的节点重跑失败或停止时，旧结果仍保持完成和可复用。

## 初始化《雨夜外卖》Demo

先确保根目录已有 `config.yaml`。初始化本身不调用供应商、不要求媒体凭据；确认后端未运行后执行：

```powershell
cd backend
npm.cmd install
npm.cmd run init:rainy-night-demo
```

脚本会写入预设故事、四场剧本、角色/场景/道具、10 个分镜、精确资产关系和 DAG 画布。它不会生成图片或视频，也不会清理已有项目；发现同一个半成品 Demo 时会原位补齐，完整 Demo 重复执行不会创建第二个项目或覆盖画布。如果只有其他普通项目而没有 Demo，则会明确拒绝。

初始化成功后启动应用，先在 AI 配置页按需把文本、图片和视频默认模型设为 Agnes 或 PearAPI 的模型，也可以全部留空；再打开《雨夜外卖》，由你在画布顶部选择“运行未完成”或“运行整个画布”。Demo 节点自身不预设供应商或模型。

`accept:rainy-night-demo` 是同一初始化入口的别名，只初始化或修复 Demo，不刷新供应商目录，也不提交任何真实生成任务：

```powershell
cd backend
npm.cmd run accept:rainy-night-demo
```

真实工作流只能在画布中由用户主动启动。上述两个初始化命令都不会调用 Agnes 或 PearAPI。

前端默认地址：`http://localhost:3012`。Vite 会把 `/api` 和 `/static` 转发到 `http://localhost:5679`。

Windows 下也可以运行根目录的 `python start.py`，它会分别打开后端和前端窗口并启动开发服务。

## 验证

```powershell
cd frontend
npm.cmd test
npm.cmd run build
npm.cmd run lint
npm.cmd audit --audit-level=moderate
```

图片和视频生成需要在根 `config.yaml` 配置可用供应商凭据，再到 AI 配置页刷新实时模型目录。没有真实凭据时，项目仍可使用手动文本、画布编排和项目管理功能，但第三方生成会明确失败。

当前处于快速开发期，不维护数据库迁移或历史数据兼容。后端启动时由唯一 TypeScript schema 补齐当前数据库结构，但普通启动、测试和构建都不会删除 `backend/data`。只有 owner 明确要求清空数据时，才由执行者先停止服务并手工删除该目录；项目不提供自动清库命令。

画布节点、坐标、依赖边、工作流组和模板由 `canvas_layout` 一次性保存；选择、框选等当前标签页状态不会入库。节点只保存当前生产角色 `role`、用户参数、资产 ID、结果、历史与状态，材料、阶段、资产分类和默认运行方式都由唯一生产目录派生。保存接口使用 `expected_revision` 做并发保护，同一旧版本不能覆盖其他页面已经保存的新版本。生成、手动保存和从画布内部跳转前都会先提交最新快照。

运行期间点击“停止运行”会立即停止前端轮询和后续节点提交，并调用 `POST /api/v1/tasks/:id/cancel` 取消当前本地任务。对于已经提交到第三方的异步生成，是否能撤销其远端计算取决于供应商；tomato-ai-drama 会停止本地跟踪并拒绝把迟到结果写成成功。

后端的完整严格 TypeScript 检查：

```powershell
cd backend
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
```
