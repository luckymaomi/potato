# 设计参考

本目录保存本地浅克隆的第三方项目，仅用于研究交互与信息架构。第三方源码目录不会进入 tomato-ai-drama 的版本控制、依赖安装或产品构建，也不会把其代码复制进产品主干。

## 本轮样本

| 本地目录 | 上游 | 调研提交 | 主要观察 |
| --- | --- | --- | --- |
| `tldraw/` | `tldraw/tldraw` | `b3914b2` | 无限画布基础交互、Workflow 与 Image Pipeline starter kit |
| `comfyui-frontend/` | `Comfy-Org/ComfyUI_frontend` | `31d1d3d` | 选择上下文工具箱、拆分运行按钮、模板选择、队列与历史反馈 |
| `aicon/` | `869413421/ai-moive-studio` | `4e0810e` | AI 视频无限画布的文本/图片/视频节点、工作台与详情编辑分层 |
| `huobao-drama/` | `chatfire-AI/huobao-drama` | `ff9b046` | 短剧项目、资产、分镜、批量视频和失败重试的业务表达 |

所有仓库使用 `--depth 1 --filter=blob:none` 浅克隆。以上提交是 2026-09-16 本地调研时的快照，不代表未来上游状态。

## 采用的模式

- 选择对象后才出现上下文命令，命令明确作用于“当前节点”或“所选节点”，避免全局工具栏含糊。
- 全局运行采用主按钮加范围菜单；单节点、所选范围、下游分支和整个画布是不同命令，不用一个“运行”承载多种猜测。
- 工作流执行由连线依赖决定，等待上游完成后再执行下游；连接同时承担必要的文本和参考图片输入。
- 默认模板是可恢复的工作区初始状态，不是一次性的教程遮罩；完整 Demo 是幂等入口，不重复制造项目。
- 节点创建后立即选中；编辑区按节点类型显示必要字段；媒体预览、状态、错误和重试都留在节点上下文内。
- 批量执行前显示节点数量，完成后分别报告成功与失败；保存的工作流组具有名称、成员和独立运行入口。
- 项目列表提供搜索和完整管理动作，打开项目由整张卡片承担，编辑、导出、删除作为次级图标命令。
- 模型参数必须跟随具体模型：AICON 把 `aspect_ratios` 放入服务端策划的模型能力目录，前端切换模型时清理无效比例，生成 payload 只提交所选模型支持的值；ComfyUI 也让比例作为具体节点定义的输入。tomato-ai-drama 采用相同职责边界，但能力来源是 Agnes 适配器协议或 PearAPI 实时丰富目录。
- 凭据可用模型与公共丰富元数据必须求交集：只展示当前 Key 真正可用的模型，再补充模式、参考图上限和比例；公共目录故障时保留可用模型身份，但把未知能力明确标为未知。
- Huobao 在项目创建时固定 16:9/9:16，适合单一成片规格；tomato-ai-drama 同一画布允许不同模型和媒体节点，因此比例保存在节点并由后端逐任务校验，项目比例只作为新节点默认值。
- 保存链路以 `C:\Users\Administrator\Desktop\repository\mo` 为主要本地蓝本：不可变快照、防抖合并、单写 Promise、expected revision、明确 dirty/error/conflict 和离开保护是可复用原则；其 IndexedDB、Web Locks 与 BroadcastChannel 服务于纯前端本地库，不复制到 Node/SQLite 架构。
- AICON 的节点级 300ms 防抖和“生成前先保存”说明高频编辑与执行边界应分开；但它的自动保存错误只写控制台且没有版本冲突保护，因此 tomato-ai-drama 只吸收交互节奏，不采用其完整保存合同。
- tldraw 将 document 与每个标签页的 camera/selection/session 分离；tomato-ai-drama 同样只保存画布业务文档，不保存 React Flow 选择态。ComfyUI 的文档架构记录强调保存只能确认请求捕获的 revision，保存期间的新修改必须继续保持 dirty；tomato-ai-drama 的串行协调器按该规则实现。
- Huobao 把提示词文件作为生成、查看和编辑的同一来源；tomato-ai-drama 因此前移默认系统提示词为后端唯一目录，并让画布检查器读取、编辑和恢复同一份默认值。
- ComfyUI 由节点定义驱动菜单、画布和参数面板；tomato-ai-drama 的生产角色目录同样是创建工具、默认模板、节点卡片与检查器语义的唯一来源，不再维护多套节点枚举。
- AICON 明确区分稳定资产、分镜关键帧和镜头视频；tomato-ai-drama 采用“材料 + 生产用途 + 资产分类”合同表达同一核心链，不引入其大型 Agent 或队列体系。

## 明确不照搬

- 不采用 Huobao 的固定阶段表单和左侧进度轨，本产品保持纯画布主体验。
- 不引入 ComfyUI 的大型扩展、队列、模型管理和多标签架构，只吸收选择与运行反馈。
- 不引入 tldraw SDK 或其许可约束，继续使用已经确定的 React Flow。
- 不复制 AICON 的旧 JavaScript/Vue 实现、Assistant 侧栏或整图/节点双持久化模式。
- 不引入 CRDT、实时多人同步或浏览器本地数据库；当前产品是本地 Node 服务的单用户工作台，服务端 optimistic revision 已足够阻止旧页面覆盖。
- 不使用任何单边彩色竖条、状态 rail、`border-left`、`border-right` 或伪元素侧边强调。
- 不复制参考项目源码、品牌、素材或视觉皮肤；tomato-ai-drama 保持自己的 TypeScript 架构与视觉语言。
